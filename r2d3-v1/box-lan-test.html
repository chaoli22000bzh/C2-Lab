R2D3 : box Internet, recette LAN + DHCP

Premier test fonctionnel : deux PC branchés sur LAN 1 et LAN 2 et un PC Wi-Fi doivent recevoir des adresses différentes, attribuées par le même routeur DHCP.

Topologie fixe

Routeur LAN 192.168.1.1/24 → switch port 6. Point d'accès Wi-Fi → switch port 5. PC-A → LAN 1. PC-B → LAN 2. PC-Wi-Fi → SSID BOX-WIFI.

DHCP : 192.168.1.100 à 192.168.1.200. Aucun VLAN. Les liaisons internes sont permanentes.

Choisir un test.

Ce banc de recette utilise le registre R2D3 et le Core DHCP commun. Il ne simule pas encore le WAN, NAT/PAT, VPN ou le mode bridge.
