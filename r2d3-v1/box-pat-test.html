R2D3 : PAT entrant sur une box Internet

Recette du moteur commun de redirection de port. Un client situé sur l’Internet simulé tente d’accéder à un serveur Web du LAN de la box.

Configuration du scénario

Client Internet : 90.14.20.22. Box : 90.14.10.20. Règle PAT : TCP 8080 → 192.168.1.110:80. Serveur Web SRV-WEB du registre R2D3 raccordé sur LAN 1, avec HTTP activé dans le Core commun.

Aucun modem, FAI ni câble WAN. Chaque bouton reconstruit un scénario indépendant.

Sélectionne un test.

Le test interroge le moteur d’état des services R2D3. Il simule le routage et l'accès HTTP, sans véritables sockets, sans Internet réel et sans requête HTTP transmise sur le réseau. L'administration de la box sera intégrée dans un lot séparé.
