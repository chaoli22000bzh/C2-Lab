Vérifier les commandes Windows

Les exemples ci-dessous appellent directement les modules partagés. Les valeurs sont des données de démonstration, pas les résultats d'une machine réelle. Aucun rendu n'est recopié dans cette page.

1. ipconfig

Choisir un état réseau pour contrôler le résultat.







2. ipconfig /all


Même affichage partagé pour les cas IP fixe, DHCP et APIPA.










3. ARP


La table ARP est propre à chaque PC : les actions ci-dessous modifient uniquement les données de démonstration.










4. ipconfig /release et /renew


Sorties du composant partagé à partir de données DHCP de démonstration.
