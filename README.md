# C2-Lab

Laboratoire de tests des simulateurs pédagogiques.

Documentation et catalogue de référence : [C2/main/docs](https://github.com/chaoli22000bzh/C2/tree/main/docs) (dépôt privé).

## Recette autonome des switchs L2/L3

[Administration graphique des switchs (v6.11)](https://chaoli22000bzh.github.io/C2-Lab/r2d3-v1/switch-admin-ui-v1.html?v=6.11) : essais des ports Access/Trunk, VLAN, IPv4 de gestion, routage inter-VLAN, IP Helper et DHCP L3, selon les capacités de l'équipement. Les fichiers `r2d3-v1/switch-admin-ui-v1.js` et `.css` sont des **copies synchronisées** des composants communs `R2D3/src/`, non des implémentations métier indépendantes.

Les spécifications et le suivi des recettes sont maintenus uniquement dans [C2/docs](https://github.com/chaoli22000bzh/C2/tree/main/docs). **C2-Lab est un laboratoire autonome ; l'intégration de R2D3 dans C² n'a pas été commencée**, et ses tests ne prouvent aucune compatibilité de production ou persistance des séances C².
